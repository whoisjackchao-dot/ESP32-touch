## 阻塞

| 项 | 原因 | 解除条件 |
| --- | --- | --- |
| `B09` 按键逐键 | `E26` 真机按压只观测到 KEY2；KEY1/PWR 未观测到（**未结论**） | 用户在场时跑 `keyprobe.py`（90 s 原始电平）确认 GPIO0/4/5 与物理键映射，再跑 20 次/项 |
| `KEY-01/02/05` 真机按压 | 插件运行时会占用 COM7，需临时停插件/停 DSH 才能采集；`B09` 未关闭 | 用户临时退出 DSH（约 3 分钟）→ `keyprobe.py` + `keyh_capture.py` |
| 触摸变体 | 实机 `IC id: 182`（0xB6），与"CST816S"命名不完全一致（`B06`） | 二期立项 |
| 触摸/IMU/AEC/OTA | 已批准**后置**（`Q03`），非阻塞第一版 | 二期立项 |
| `G1` 计数口径 | 原文"6 态各 4 次共 20 次"，算术 24（`C03 §7 R8`） | 用户确认门槛分母（实测按 24/24） |
