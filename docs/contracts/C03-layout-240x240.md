# C03：240×240 版式契约（M2，冻结）

> 状态：**已冻结（2026-10-30）**。本契约只覆盖值班页（宠物 + 任务卡栈）；番茄钟/菜单在 M3 另立。
> 依据：M1 实测面板 240×240、无偏移、`data_endian=LITTLE`（E14）。

## 1. 网格

坐标原点左上，x∈[0,239]，y∈[0,239]，单位 px，RGB565。

| 区域 | 矩形 (x, y, w, h) | 说明 |
| --- | --- | --- |
| 状态条 | `(0, 0, 240, 12)` | 左上 4×4 网络点；右侧电池/时间（M3 前可空） |
| 宠物 | `(72, 20, 96, 128)` | 48×64 立绘 ×2；底部 y=147 |
| 状态标记 | 宠物上方居中，`y=2..14` | WORKING=`>`，INPUT_REQUIRED=`!?`；其余不画 |
| 卡片 1（最新） | `(4, 152, 232, 28)` | 顶部卡 |
| 卡片 2 | `(4, 180, 232, 28)` | |
| 卡片 3（最旧） | `(4, 208, 232, 28)` | 底部 y=235 |
| 页脚 | `(0, 236, 240, 4)` | 预留；M2 不绘制文字 |

**不变量**：任何区域不得重叠；宠物矩形固定；卡片区始终从 y=152 起、固定 28 px 行高。

## 2. 卡片内部版式（232×28）

| 行 | 位置 | 内容 |
| --- | --- | --- |
| 行 1 | `(x+4, y+3)`，最大宽 224 | `[前缀] 项目`：`OC:` / `CC:` / `CX:` 等 3 字符前缀 + 空格 + project |
| 行 2 | `(x+4, y+14)`，最大宽 180 | `title`，超出截断并以 `…`（ASCII）或 `..` 结尾 |
| 行 2 右 | 右对齐，`y+14` | `elapsed_s` 格式 `12m` / `1h02m`；宽 ≤ 44 px |

- 字体：8×8 ASCII（scale 1）；CJK 16×16 由 `pet_text` 处理，宽度按 16 px 计。
- 颜色：底 `0x0000`；卡底 `0x18E3`；正文 `0xFFFF`；项目/时长 `0x8410`；最新卡左侧 2 px 强调条 `0x05FF`。
- 空字段：`project` 为空时显示 `-`；`title` 为空时显示 `(untitled)`，**不得留空**。

## 3. 栈规则

1. `cards[0]` 为最新，渲染在 y=152；`cards[1]` y=180；`cards[2]` y=208。
2. 同名（title 相同且 project 相同）更新：移到 `cards[0]`，保留其余相对顺序。
3. 第 4 张到达：丢弃 `cards[2]`（最旧），新卡进 `cards[0]`。
4. `card_count=0`：卡片区留黑，不画空框。
5. 状态为 OFFLINE：整屏灰度（宠物 + 卡片），状态点变红 `0xF800`。

## 4. 实现边界（架构决定）

- **新增** `firmware/components/pet_ui/pet_ui_240.c/.h`，提供：
  - `void pet_ui_scene_240(const pet_view_t *v, const pet_look_t *look, pet_surface_t *s);`
  - `void pet_ui_card_240(const pet_card_t *c, pet_surface_t *s, int x, int y, bool newest);`
- **不修改** 上游 `pet_render_scene/pomo/menu/skit` 的 135×240 坐标；它们在本项目只是死代码，最终由链接器丢弃。
- 复用 `pet_render_pet`（2×）与 `pet_text_draw`；颜色常量集中在 `pet_ui_240.c` 顶部。
- 业务层不得出现 135/240 坐标数字；只调用 `pet_ui_scene_240`。

## 5. 验收

| 用例 | 判定 |
| --- | --- |
| `UI-10` | 6 态各进入/退出 4 次，共 20 次，宠物形态可辨（G1） |

| `CARD-10` | 3 卡注入，最新在顶、最旧在底，20/20（G3） |
| `CARD-11` | 第 4 卡到达，最旧被淘汰，20/20 |
| `CARD-12` | 同名卡更新置顶，20/20 |
| `CARD-13` | 空 title/project 不出现空白卡 |
| `UI-12` | OFFLINE 整屏灰度且状态点红 |

## 6. 变更方式

坐标/行高/颜色任一变更 → 修订本文件 + 重跑 `UI-10..12`、`CARD-10..13`；不得在实现里加临时偏移。
