# C07：按键映射契约（M3，冻结）

> 状态：**已冻结（2026-10-31，M3 开工）**。冻结后任何变更必须记录原因、影响面与重跑用例。
> 依据：`02-requirements.md` `R17`（PWR 保留电源语义、两键完成核心操作）、`Q03`（最小可跑）；
> 硬件引脚来自 `03-feasibility.md` §5.1 原理图 GPIO→网络表（`E06–E09` 只读核对，按键未逐键实测，`B09`）。
> 上游行为规格参考 `ESP32-buddy/contracts/M6-按键映射契约清单.md`（MIT，仅行为参考，代码按本项目重写）。

## 1. 硬件事实与假设

| 键 | GPIO（原理图） | 电平 | 备注 |
| --- | --- | --- | --- |
| `KEY1`（BOOT/MINUS） | **GPIO0** | 低有效，10K 上拉 | 复位时按住进下载模式；**运行期可作普通输入** |
| `KEY2`（PLUS） | **GPIO4** | 低有效，10K 上拉 | |
| `PWR` | **GPIO5** | 低有效 | **系统电源键**；长按关机（拉低 GPIO2 锁存）；短按不得触发应用动作 |

**假设（M3 真机验证项 `B09`）**：GPIO0/4/5 可作为 GPIO 输入读取，低=按下；`PWR` 长按可经
`GPIO2=0` 关机。若实测不符，**停止并按停止条件回到本节**（不得临时改映射绕过）。
`GPIO45/46` 是 strapping，禁止在此用作按键；`GPIO2` 只作电源锁存输出。

## 2. 采样与判定（纯逻辑，host 可测）

| 项 | 值 | 说明 |
| --- | --- | --- |
| 采样周期 | **20 ms**（`KEY_DEBOUNCE_MS`） | 每拍读一次 GPIO；**首次翻转即生效**（不做多数表决） |
| 长按阈值 | **600 ms**（`KEY_LONGPRESS_MS`） | 按住达到阈值时触发**一次** LONG |
| 短按判定 | **松键时** | 按住 < 600 ms 判 SHORT；LONG 已触发则松键不再判 SHORT |
| 长按后松键 | 发 RELEASE，不发 SHORT | |
| 事件队列 | 队深 3，FIFO | 松键沿可能同时产 SHORT+RELEASE；仅病态抖动丢最旧 |
| PWR 长按阈值 | **1500 ms**（`PWR_LONGPRESS_MS`） | 与两应用键不同阈值；短按无动作 |

> `PRESS`/`RELEASE` 事件保留（M4 语音 PTT 用）；M3 的键表只消费 `SHORT`/`LONG`。

## 3. 映射表（冻结）

| 键 + 事件 | 值班（DUTY） | 番茄钟（POMO） | 菜单打开时 |
| --- | --- | --- | --- |
| `KEY1` 短按 | `PET_ACT_SEND`（M3 未接宿主：只记日志；M5 接事件通道） | `PET_ACT_POMO_SHORT` 开始/暂停/继续/推进 | 选中项移到下一项（循环 5 项） |
| `KEY1` 长按 | `PET_ACT_MUTE_TOGGLE` 静音翻转（**持久化**，`R15`） | `PET_ACT_POMO_LONG` 放弃番茄钟 | 无动作（只记日志） |
| `KEY2` 短按 | `PET_ACT_MODE_POMO` 切到番茄钟 | `PET_ACT_MODE_DUTY` 切回值班（先落盘统计） | 执行选中项（见 §4） |
| `KEY2` 长按 | `PET_ACT_MENU` 打开菜单 | `PET_ACT_MENU` 打开菜单 | 关闭菜单 |
| `PWR` 长按 ≥1500 ms | 关机流程（§5） | 同左 | 同左 |
| `PWR` 短按 | **无动作**（`R17`） | 无动作 | 无动作 |

- 菜单打开时，`KEY1/KEY2` **不再触发主界面动作**。
- 长按阈值 600 ms 为**提案值**（上游同为提案，`Q11` 未批数值）→ 做成编译期可覆盖。

## 4. 菜单项（5 项，冻结）

| # | 文案 | 选中后 `KEY2` 短按 | 备注 |
| --- | --- | --- | --- |
| 0 | `MUTE: ON/OFF` | 静音翻转 + 持久化，**留在菜单** | `R15` |
| 1 | `STATUS` | 关闭菜单（状态只读） | 菜单页底部已显示统计 |
| 2 | `WIFI (M5)` | 关闭菜单 + 日志 `M5 not implemented` | 网络属 M5，**不假装可用** |
| 3 | `BT (M5)` | 同上 | 同上 |
| 4 | `BACK` | 关闭菜单 | |

- 打开菜单时选中项重置为 `0`（MUTE）。
- 菜单页 240×240 版式见 `docs/10-m3-development.md` §5。

## 5. `PWR` 关机流程（冻结）

1. 先**落盘**：番茄钟统计（若本段有未保存变更）、静音标志。
2. 背光关（LEDC duty 0）。
3. `GPIO2 = 0`（释放电池供电锁存）。
4. 不得再返回应用层。

**明确声明**：USB 供电时拉低 GPIO2 **不会**真正断电（物理事实），设备会停在该状态；
电池供电时才会关机，重新上电需按 `PWR`。测试时必须记录供电方式。

## 6. 明确不做

- 不做双击、组合键、长按连发、按住重复。
- 不把 `PWR` 用作第三个 UI 键；不拦截 `PWR` 的电源语义。
- 不做按键自定义/学习。
- 不做触摸（后置 `R18`）。

## 7. 验收用例

| 用例 | 判定 | 类别 |
| --- | --- | --- |
| `KEY-01` | 两键短按各 20 次，动作与 §3 一致，无误触发/漏触发（每项 ≥19/20） | H |
| `KEY-02` | 两键长按各 20 次，动作与 §3 一致（每项 ≥19/20） | H |
| `KEY-03` | 600 ms 边界：590 ms 判短、610 ms 判长（host 断言） | T |
| `KEY-04` | 菜单内 5 项循环选中、执行、关闭；菜单内主界面动作不触发 | T+H |
| `KEY-05` | `PWR` 长按 5/5 进入关机流程；短按 5/5 无应用动作 | H（USB 下记录"未真断电"） |
| `BTN-01` | 事件队列顺序/不丢（松键 SHORT→RELEASE） | T |

## 8. 变更方式

键位、阈值、映射任一变更 → 修订本文件 + 重跑 `KEY-01..05`、`BTN-01`；变更记录写明日期、原因与影响面。
