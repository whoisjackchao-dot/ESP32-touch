## 6. 覆盖缺口（如实）

- ~~无 host C 单测~~ → **已补**：`tests/`（mingw gcc，14 用例/214 断言，RED→GREEN 留档）；仍未接入 CI。
- **帧率只有设备自报 `fps`**（`STATUS ... fps=8`），`FRM-01` 的撕裂/闪烁仍需人眼（无摄像头）。
- **无内存仪器**：`MEM-01` 只用 `STATUS heap=` 采样 10 min（`E19`），无 heap 碎片/泄漏断言的细分追踪。
- **电池未验**：`PWR-01` 只走了 USB。
- **注入通道是 M2 调试接口**（串口单字符），不是产品接口；M5 由事件协议取代前不得对外承诺兼容。
