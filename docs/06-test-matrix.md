# 测试用例与追踪矩阵

> 追踪链：`R → 用例 → M → 证据`。
> 证据等级：**T** host 单测 / **C** 契约检查 / **H** 真机 / **D** 文档。
> 状态：`PASS` / `FAIL` / `PARTIAL` / `PENDING` / `N/A`。
> 失败样本不剔除；`PARTIAL` 必须写明缺哪一半。

## 4. 已知缺陷与回归

| 缺陷 | 现象 | 根因 | 回归用例 | 状态 |

## 5. 覆盖缺口（如实）

- **无 host C 单测**：本机无 `cc`；当前 T 类只有"构建成功"，没有断言级单测。→ 需在 M2 后补 `zig cc` 或用户态 gcc。
- **无帧率测量**：`FRM-01` 目前只能目视"不闪"，没有 fps 数值。
- **无内存测量**：`MEM-01` 需 `heap_caps_get_free_size` 日志，尚未加。
- **电池未验**：`PWR-01` 只走了 USB。
