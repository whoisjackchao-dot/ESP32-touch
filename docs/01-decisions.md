## 4. 可逆 vs 不可逆

| 类型 | 谁决定 |
| --- | --- |
| 可逆工程细节（目录结构、模块命名、内部实现、日志格式） | 执行者自行决定 |
| **不可逆产品语义**（许可、数据外发、云端费用、发布账号、是否独立可用、AEC 承诺、触摸/IMU 是否是唯一入口） | **必须用户批准，不得代批** |
| 物理风险（GPIO2 电源锁存、strapping 脚、面板初始化） | 执行者按官方资料实现，但**首次上电必须用户在场/授权** |
